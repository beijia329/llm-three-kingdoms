**主题：程序化地图生成 + 古地图渲染 + v2.3 收口**

核心是让地图从"手工数据"走向"程序生成"。

- **MapGenerator**：15 种地形 + 气候带 + 大陆塑形，地形配比调优；bbox 预计算把生成从 28s 压到 1.4s
- **地图扩展**：180×128 格覆盖全中国（85–130°E, 18–50°N），加空气墙与探索迷雾
- **中国 GeoJSON 掩码 + 古代州郡体系**：Total War 风格渲染（暖色版图 / 深色外域 / 蓝色海洋，三层色系）
- **势力配色**：按 184 年初始关系决定冷暖（盟友暖色、敌人冷色），且不用蓝色系做势力色
- **城市坐标抽离**：`city_positions.json`（989 B，替代原先 968 KB 的内嵌数据）
- **Web 同步**：15 种地形配色、连续版图轮廓、flood-fill 渲染
- **收口**：修 GUI 崩溃 / 依赖缺口 / API key 改名（`LLM_API_KEY`）/ 文档全扫对齐 / 补 Phase7 验收脚本 / 新增 ADR-0001~0004
