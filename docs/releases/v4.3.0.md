**主题：把「一统天下」还给真正的一统，把棋盘还给眼睛**

> 发布于 2026-10-04

本轮由三条玩家试玩反馈驱动，先出三份规范文档（美术·战棋视觉 / 美术·UI 古韵 / 设计·胜负条件），
再按规范落地。核心是两件事：**结束判定不再含混**（「城市最多者胜」与「统一」彻底分开），
**地图不再是一团色斑**（格网 / 层级 / 标尺 / 尺寸档）。

---

### ⚖️ 玩法：三层结束语义 + 僵局熔断（方案 A′）

**问题**：结束界面把「回合耗尽 · 城市最多者胜」写成了「一统天下」，同一张卡内还自相矛盾
（大标题「一统天下」、副行「回合耗尽」，而汉室/黄巾仍存活）。根因是**代码分得清「谁第一」，
文案分不清「第一」与「统一」**，且引擎 / 后端事件 / 前端结算卡三处口径各写各的。

**现在**：

- **三层结局**：引擎新增 `end_reason ∈ {unification, timeout, stalemate}`。
  - `unification`（真胜利）：地图上全部「有主城」归一（= 非中立城只剩一个主人；**中立城不计入**）。
  - `timeout`（时限）：standard 模式到达 `max_turns`，或无限模式到达软上限兜底 → 领先者「领先胜出」。
  - `stalemate`（僵局）：无限模式下连续 `stalemate_turns` 回合零战斗 → 领先者「领先胜出」。
  - 🔴 **非 unification 结局在任何界面不再出现「统一 / 一统天下」**。
- **默认对局长度改为「无限 + 僵局熔断」**（方案 A′）：默认 `game_mode="infinite"`、
  `max_turns=192`（软上限/兜底）、`stalemate_turns=6`。有战事就打到统一；一旦进入历史观测到的
  「无人再打仗」空转区，约第 55 回合熔断收束。48 回合保留为可选短场/压测档（`--max-turns 48`）。
- **终局文案单一真源**：新增 `game/end_copy.py::format_end_copy`（文案）与 `format_end_icon`（图标）；
  `/api/state` 下发 `end_title` / `end_subtitle` / `end_icon`（与 `game_over`/`winner` 同级）。
  后端事件流与前端结算卡**一律 verbatim 取用**，杜绝三处漂移。`end_reason` 未知（旧档）时保守按
  timeout 口径，**绝不臆造「一统天下」**。
- 交付物：`tests/unit/test_check_victory.py`（三态 / 中立城α / 被围未陷落 / 残军 / 领先者确定性 /
  后端文案契约，18 例）、`tests/unit/test_end_copy.py`（四结局 / 事件同源 / 状态字段契约 / 图标真源，20 例）。

### 🗺️ 战棋视觉：格网 · 层级 · 标尺

**问题**：全图未缩放时整块陆地是连续色块——看不到六角格网，分不清国界与行政区界，城池与军队比例重叠。

**现在**：

- **六角格网**：给陆地格描细发线格网（**全图默认视角也可见**，全图更淡、放大更显）；线宽**屏幕恒定**
  （世界px ÷ zoom，缩小不再糊）。
- **四级线宽**：省界（若有）< **州郡界 1.8px** < **势力界 3.0px（势力色）** < **交战前线 3.0px 朱红**
  （外侧 1px 亮描边）。交战前线数据来自 `/api/state` 新下发的 `at_war_pairs`（两方 `at_war` 的接壤边界）。
- **地形 LOD 三档**：`<0.30` 只纸色 / `0.30–0.55` 大轮廓 / `≥0.55` 全符号；
  符号按古法制图：山「人」字 ∧ + 单侧阴影排线、林锥形簇、沙漠点阵、沼泽短横。
- **尺寸档 + 比例硬规则**：
  - 城池五档 **14/16/19/22/26px**（按等级），四重编码：守军血条 / 城墙盾 / 民心点 / 围城塔；
    `<18px` 只留「剪影 + 势力单字」（学《陷阵之志》「一格只留一种信息」）。
  - 军队三档 **12/16/20px**（按兵力），状态剪影（行军=马 / 进攻围城=刀剑 / 撤退=盾红 / 驻守待命=盾）；
    行军中画方向短箭头。
  - 🔴 **军队标记尺寸 ≤ 同格城池标记尺寸 ×0.80**；同格有城时军队偏移到格右下角。
- **标尺表**：新增字号(6档)/线宽(4档)/标记(5档)/不透明度(4档) 刻度 token（`FS/LW/MK/OP`）；
  领土填色 alpha 0.42→0.30（让地形透出来）；近黑势力替身色提亮
  （董卓 `#1D1B24→#5A4A63`、曹操 `#5E3828→#8A4B32`）。

### 🖌️ UI 古韵（方向甲 · 绢本墨色）

**问题**：视觉「太卡通、不古韵」——蓝紫黑底 + 电竞金 + 毛玻璃 + 大圆角 + 现代无衬线。

**现在**：

- **token 全表换血**：底 `#16222B`（墨青）/ 金 `#C8A85A`（赭金）/ 朱砂 `#9D2933` /
  天青 `#4A6FA5` / 竹青 `#5B7A4E` / 藕紫 `#6B5A82`；新增 `ink / paper / accentStamp / ochre / divider`。
  注入全局 CSS 变量（`--bg / --gold / --font-serif …`）。
- **清硬编码色**：`#d4a84b` **65 处 / 16 文件 → 0**（另有 Material 三件套 `#64a0d2/#9370DB/#5ab464`
  26 处 → 0），一律走 token——消除「一调就全错」的根因。
- **去卡通**：圆角上限收到 **6px**（消灭 11 种值）；移除**全部毛玻璃**（`backdropFilter`）；去霓虹辉光
  （`SHADOWS` 降强度）；衬线栈从「标题」扩到「标题 + 区块标题 + 势力名 + 数值单元标题」
  （正文 / 事件流保持无衬线，**零体积**）。

### 🐛 顺带修复的两个隐藏缺陷

- **生产构建图标全变方块**：Vite 把 <4KB SVG 内联成含**单引号**的 data URI，
  而代码拼的是**未加引号**的 `url(...)` → CSS 非法 → 浏览器丢弃 `mask-image` → 只剩底色成实心方块
  （**仅生产构建复现**，dev 看不出）。修复：全仓 12 处 `url()` 统一加引号
  （`GameOverOverlay`/`BattleOverlay`/`CityMarker`/`ArmyMarker`/`EventTicker` 的 mask +
  `CityCard`/`ShortcutHelp` 的 borderImage）+ `vite.config.ts` 设 `assetsInlineLimit: 0`。
- **`crown.svg` 背景圆遮挡**：其首层无 fill 的背景圆在 mask（按 alpha）下遮死整框 → 皇冠显示为圆盘。
  修复：删除背景圆，仅留王冠 path。
