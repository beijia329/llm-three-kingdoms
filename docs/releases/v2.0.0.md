**主题：换成真实中国地图，十二路诸侯登场**

从"简化版三国"跨到"真实地理上的三国"：

- **六角格地图体系**：HexCoord 坐标换算、Tile 数据模型、A* 寻路，地形扩展到 15 种
- **真实中国地图**：中国省界矢量底图 + 经纬度投影校准（样点对齐真实 GIS 数据）
- **12 势力 184 年剧本**：汉室 / 黄巾 / 董卓 / 袁绍 / 曹操 / 刘备 / 孙坚 / 刘表 / 刘焉 / 公孙瓒 / 马腾 / 袁术，22 城
- **季节与时间线**：每回合 = 1 季度，184 年黄巾起义开局
- **影响力系统**：地块影响力扩散 + Buff / Debuff 计算
- **建国系统**：3 城称王、5 城称帝，配历史国号与增益
- **性格系统**：将领性格 + 势力战略倾向，进入决策
- **渲染升级**：相机系统、势力边界、47 名将领、六角格城池与军队绘制
