**主题：把「围城」变成看得见的持续状态，给「抢哪个州」一个答案**

> 发布于 2026-10-04

这一版由第三批遗留问题清单驱动，清三个点：**围城名不副实**、**州郡层零差异化**、
**`_redirect_army_home` 无单测**。

---

### 🏯 围城持续化 + 断粮（本批核心）

**问题**（`docs/qa/v4.1.2-audit.md`、`docs/design/v4.1-gameplay-gaps.md` §3）：
军队抵达敌城后**同回合立即总攻**，结算时 `is_besieged` 清零 ——
「围城」只是单回合内的瞬时战斗，任何回合边界的外部观察者（LLM / 前端 / 回放）
都看不到它；「断粮」也只有军队层面（army food=0 → 士气 -10），城市层面没有。
前端为此准备的围城徽记 / 脉冲组件（`CityMarker.tsx`）因此**几乎从不显示**。

**现在**：

- **不立即总攻**：抵达后保持围城；`battle_scheduler.detect_battles` 改为
  「仅当总攻条件满足时」才产出战斗。
- **每回合围城结算**（挂 `AFTER_MOVEMENT` 相位钩子，注册名 `city_siege`）：
  - 城墙持续受损（`SIEGE_WALL_DAMAGE_PER_TURN`）；
  - 被围城市**粮草不产出**（`ResourceSystem` 内 `is_besieged` 判定）+ 照常扣守军消耗；
  - 粮草 ≤ 0 → **断粮**：民心 -5（已有机制）**+ 新增守军减员** `SIEGE_STARVATION_GARRISON_RATE = 0.02`
    （每回合 -2%，整数截断，绝不打到 0）；
  - 攻方粮草 ≤ 0 → **撤围**（复用 `_redirect_army_home`）。
- **总攻条件**（满足任一）：城墙 hp ≤ 0 ／ 守军断粮累计 ≥ `SIEGE_STARVATION_ASSAULT_TURNS = 2` 回合 ／
  围城持续 ≥ `SIEGE_ASSAULT_AFTER_TURNS = 3` 回合。
- **回滚开关**：`GameConfig.siege_persistent`（默认 `True`；设 `False` 时行为**完全退回 v4.1.2**，
  有单测守卫）。
- **可观测**：每回合围城结算写入事件流，如「【围城】曹操 围困 许昌（城墙 2400→2000）」；
  前端围城徽记/脉冲由持续状态自动激活。
- 新增 `tests/unit/test_siege_state.py`（25 例，逐条改坏验证）。

#### 平衡对照（`tests/balance/exp11` / `exp12`，5 局 × 48 回合，seeds 1–5）

| 指标 | 围城持续化 ON | OFF（v4.1.2） |
|---|---|---|
| 平均战斗场次 | 54.8 | 73.6 |
| 平均存活势力数 | 10.0 | 9.6 |
| 平均 HHI | 0.1756 | 0.1799 |
| 平均 top_share | 0.321 | 0.318 |
| 地图冻结回合（末次易主） | 45.6 | 46.4 |
| 出现灭国的局数 | 5/5（首灭 24.2） | 5/5（首灭 20.6） |
| 僵尸军队峰值 | 1 | 0 |
| 困在军队的兵力占比 | 7.6% | 7.7% |

**结论：未加剧「打不完」问题。**
围城持续化使战斗场次下降约 25%（围城需 3 回合才总攻，这是设计使然），
僵持类指标（存活势力 +0.4、首灭回合 +3.6）轻微上升，但差异均在 5 局噪声量级内，
且攻方胜率反而略升（exp11：84.7% vs 81.2%）。
全部围城常量标 `[PLACEHOLDER]`；若后续希望恢复战斗频率，调低 `SIEGE_ASSAULT_AFTER_TURNS`
或提高 `SIEGE_WALL_DAMAGE_PER_TURN` 即可。

### 💹 州郡生产 modifier

**问题**（`docs/qa/v4.1.2-audit.md` §5.3）：v4.1.2 完成了**势力层**差异化，
但**州郡层完全未动** —— 31 座城在数值上只有 `level` 不同，地理只影响寻路距离，
「抢哪个州」在开局没有非对称答案。

**现在**：13 州各一个单一生产 modifier。

| 州 | modifier | 说明 |
|---|---|---|
| 司隶 / 扬州 | gold ×1.15 | 京畿重地 / 江东富庶 |
| 豫州 / 青州 | gold ×1.10 | 中原腹地 / 渔盐之利 |
| 益州 | food ×1.20 | 天府之国 |
| 冀州 | food ×1.15 | 河北粮仓 |
| 兖州 / 徐州 / 荆州 | food ×1.10 | 中原粮区 / 沃野 / 湖广熟 |
| 凉州 / 幽州 | recruit ×0.90 | 西凉铁骑 / 幽州突骑（征兵更便宜） |
| 并州 | recruit ×0.95 | 边地尚武 |
| 交州 | gold ×0.90 | 蛮荒之地（唯一负面） |

- 落点：`ResourceSystem` 产出 × 州倍率（钱 / 粮正交，互不影响）、`CitySystem.recruit` 成本 × 州倍率。
- 引擎侧正本 `game/provinces.py`；数据行 `data/provinces.json`（两者一致性由单测守卫，防分叉）。
- 前端城池卡显示州 modifier 说明；LLM 提示词新增「州郡差异」段。
- 新增 `tests/unit/test_province_modifiers.py`（12 例）。
