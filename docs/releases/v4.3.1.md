### 🧭 外交面板纵向版式（M4 完整版）

**问题**（`docs/art/2026-10-04-UI古韵方向.md` §4.1、`M4-measurements.json`）：
上批只做了「环形图 / 关系矩阵」二选一，但面板仅 300px —— 12×12 关系矩阵的格子太小
（<18px 难辨单字徽标），且图例与矩阵挤在一处。

**现在**：

- **面板宽度 300 → 420**（宽屏基准）。🔴 **不全局写死 420**：新增
  `responsivePanelWidth(viewportW)` 与 `usePanelWidth()` hook，按视口取三档
  **≥1440 → 420 / 1200–1439 → 360 / <1200 → 300**；App / TopBar / EventTicker / Panel
  四处浮层的 `right` 偏移**统一走同一事实源**（否则一改宽度四处错位 —— v4.2.0 M5 的教训）。
  → 1366 屏地图仍 ≥1000px、1280 屏 ≥920px，**不把地图压到不可用**。
  （比「面板可折叠」更省事、无交互成本，故未加折叠开关。）
- **关系矩阵格自适应、下限 18px**：`cell = clamp(⌊(panelW−28)/13⌋, 18, 26)` →
  420 栏 = 26 / 360 栏 = 25 / 300 栏 = 20，全部 ≥18；**图例另起一行**（矩阵下方独占一行）。
- 保留上批「环形图 / 关系矩阵」二选一开关 + 「当前战况摘要」默认折叠。

### 🎯 战斗聚焦（H3，art §4.6）

**问题**（QA 基线 H3）：全图未缩放时，多场战斗的三层箭头（暗 casing + 势力色主线 +
亮芯）× 州郡墨线 × 河流 × 多路合攻扇形线在洛阳—陈留—许昌一带叠加成**线团**，
看不出哪条线属于哪场战斗。

**现在**：

- **同屏最多高亮 1 场战斗**：聚焦场 = 正在回放者，否则**最新一场**；其余全部降为
  「**弱提示**」——线宽减半、不透明度 ≈0.16、**不画亮芯 / 不画起点圆 / 不画爆点 / 不显示标签**。
- 战斗标签**加底衬**：近实底（0.96）+ `0 0 0 2px` 外描边，避免被穿过的线条干扰；
  非回放时也常驻显示「最新一场」标签，让观众随时知道最近发生了什么。
- 结果环收敛为聚焦这一场（**同屏 ≤1**），三态结论仍由环的线型 × 颜色 × 图标三重编码承载。

### 🧹 装饰 emoji 清理

上批去 emoji 只覆盖了主界面路径，这批清掉非界面路径的残留：

- `game/engine.py` 的 `logger.info("🏰 …")` 去掉 🏰（纯文本日志；图标由前端按事件 type 渲染）。
- `renderer/`（Pygame 降级通道）**22 行**去掉 🏆 / ⚖ / 🏰 / ⚔ / ✉ / 💰 / 🌾 / 👥 / ❤ / 🛡 /
  🚩 / 🏙 / 🔧 / ❌ 等彩色 emoji（Pygame 默认字库多无法渲染，且与「古韵」定位冲突）。
- **保留** ★（等级星，几何符号）与 U+26A0 `⚠`（警示符，非彩色）——按口径不属「装饰 emoji」；
  源码注释里的 🔴 / ⚠️ 标记为非运行时输出，未动。

### 🧩 技术债：`maskStyle` 合并

**问题**：`maskStyle()` 分散在 5 处（CityMarker / ArmyMarker 各一份本地函数 +
BattleOverlay / GameOverOverlay / EventTicker 三处内联），改一处极易漏改其余 ——
这正是 v4.3.0「生产构建 mask URL 未加引号」那次只修了 2 处、漏了 4 处的**根因**。

**现在**：收敛为单一实现 **`web/src/utils/mask.ts::maskStyle()`**，5 处全部改为引用它；
`url()` 一律带引号（配合 `vite.config` 的 `assetsInlineLimit: 0` 双保险）。
