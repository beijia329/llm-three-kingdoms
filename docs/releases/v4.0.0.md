**主题：从「能跑」到「打得起来、看得懂、有戏」**

> 发布于 2026-10-03

这一版集中处理三类问题：从未生效的机制、让对局打不完的缺陷、武将数据的可见性。所有结论都来自对照实验（约 400 局 headless 模拟），不是读代码推断的。

### ⚔️ 战斗机制

- **修复「野外僵尸军队」**（最严重）
  战败撤退的部队只被改状态、不重算回程路径，且到达判定只对行军状态生效，于是走完去程路径后永久卡死——不参战、不归建、不清理，只能靠断粮每回合掉 10% 兵力慢慢蒸发。实测 155 场战斗中有 35 场撤退 + 8 场守方胜的攻方残部全部进入该状态。修复后僵尸军队峰值 4 → 0，终局残留部队 6 → 2（剩 2 支为正常行军）。
- **修复城墙上限无限膨胀**
  「发展军事」每次操作永久抬高城墙耐久上限（实测许昌 40 回合 3200→7400，+131%），反复发展的城市会变成理论上不可攻破的堡垒。改为上限由数据决定、只修复不膨胀；城墙已满时转为训练守军，避免操作空耗。
- **修复城墙已破仍享城墙加成**
  守方在巷战阶段（城墙已被打穿）仍无条件得到 1.1 倍防御加成，语义矛盾，且让攻方长期恒亏 10%。
- 修复撤退部队无路可回时的兵力蒸发；修复将领被「送进」敌方城市。

实测效果：战斗场次 155 → 199（+28%），攻方胜率 72.3% → 79.4%。

### 🧠 LLM 并发化

- 12 方串行的阻塞式 LLM 调用改为线程池并发，单回合从分钟级降至约单方耗时。新增 `GameConfig.parallel_players` / `max_workers`，可一键退回串行做对照。
- 并发不破坏确定性：观察在主线程串行生成，命令按固定顺序执行，新增单元测试逐回合比对状态指纹，证明并发与串行结果完全一致。
- 单个势力决策抛异常不再让整回合崩掉（该方按兵不动，其余照常推进）。

### 👤 武将系统

- **五行相克**（参考《全面战争：三国》）
  火=勇武 / 土=统帅 / 金=智力 / 水=政治 / 木=忠诚，相克环 火→金→木→土→水→火，克制方 +15% / 被克方 -15%。
- **智力接入攻城**：谋士第一次在战场上有实际作用（攻城器械效率）。
- **政治加成去堆叠**：原规则按城内所有将领政治求和且无上限，堆两名高政治将领即可 2 倍产出（实测单城倍率可差 2.44 倍），构成单一最优解。改为「主官全额 + 副手半额」并封顶。
- **忠诚度机制重写**：原实现因整数截断实际每回合掉 1 点，实测 144 回合后 53 名武将忠诚度全部归零；且唯一回升途径（赏赐命令）AI 全程不使用。改为向「忠诚基准」回归，并新增「失城打击」，让忠诚度由局势驱动。
- **投降机制复活**：原公式在数据实际忠诚区间内恒为负，投降从未发生过。改为按忠诚阈值分档（0% / 5% / 25% / 50% / 75%）。
- **修复俘虏链完全断裂**：战斗结算从不向战后处理传防守方将领，导致俘虏与投降整条链在生产环境永不执行（单测全绿是因为测试绕过了生产调用链）。修复后实测被俘次数 0 → 17。
- **人设档案**：为全部 53 名武将建立档案（性格 + 称号 + 特质）。原性格表 19 个键中 17 个与数据 ID 对不上（`caocao` vs `cao_cao`），且从未被任何代码读取。
- **探索人才用真实人物**：原实现用真实姓名（徐庶、庞统…）配随机属性，抽到的「庞统」可能统帅 60 政治 40。改为史实人才池。

### 🤖 LLM 与角色的关系

明确了本项目的设计立场：角色设定是「视角与偏好的起点」，不是「行动脚本」。

- 系统提示词新增「你是谁」段（注入君主称号与特质）与「关于角色与胜负的边界」段，主动解除人设对模型的束缚：可以为了取胜违背本性，不会因此判负。
- 唯一的代价来自世界本身：新增「人设代价」机制，谨慎型君主主动进攻 / 激进型君主整回合避战 → 本势力民心 -1。代价刻意做得极轻且可逆（只动民心、不动直接影响战斗力的忠诚度），使「像不像自己」成为真实的决策维度，而不是限制智能的枷锁。
- 将领表新增「称号」「将道（五行）」列，让模型能做出「派谁去打谁」的战术判断。

### 🔧 配置与工程

- **修复启动参数完全不生效**：`run_web.py --seed/--max-turns/--mode` 写入的环境变量从未被读取。
- **修复回合数自相矛盾**：系统提示写死 192 回合，而状态提示用实际回合数，改成 48 回合时模型会同时收到两条矛盾信息。
- **修复玩家种子不可复现**：使用内置 `hash()`（按进程随机加盐），同一 seed 在不同进程跑出不同对局。改用 CRC32。
- `TOTAL_CITIES` 22 → 31（与实际数据一致），并新增测试绑定两者。
- 出征兜底逻辑二次清除：87% 的进攻命令曾被引擎直接拒绝，修复后 `general_not_in_city` 归零，出征成功率 27.3% → 68.9%。

### 📊 实验与文档

新增 14 个可复现实验脚本（`tests/balance/`），累计约 400 局对照模拟，以及 3 份审计报告（回合/年份、武将数据、节奏平衡）。
