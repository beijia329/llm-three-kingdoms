**主题：第一个可运行版本——七个阶段全部完成**

> 发布于 2026-06-23

从引擎内核到 GUI 一次做通，七个阶段连续交付：

- **确定性随机**：自定义 RNG（同 seed 可复现）——这是后来一切"可复现实验"的地基
- **数据模型**：Pydantic 建模，城市 / 将领 / 军队 / 命令都有类型约束
- **事件总线**：类型化事件，供 UI 与日志订阅
- **地图与寻路**：BFS 路径与邻接关系，为后来的六角格地图留了接口
- **资源系统**：民心驱动经济产出
- **城市系统**：发展与征兵
- **将领与外交**：将领属性、外交关系雏形
- **军队行军**：移动与到达结算
- **战斗系统**：攻守判定，围城与巷战分阶段
- **LLM 接入**：DeepSeek 玩家跑通，验证了"让大模型下棋"这条路可行
- **GUI 与测试**：Pygame 渲染 + 集成测试收尾

这个版本还没有六角格地图、没有 12 势力——但它把"引擎能完整跑一局"立住了。
