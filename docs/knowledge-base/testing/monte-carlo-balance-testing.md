## 一、什么是蒙特卡洛方法

### 1.1 基本思想
通过大量随机模拟，用统计采样的方法获得数值特性。

**核心逻辑**：
- 随机生成大量输入
- 运行游戏逻辑
- 统计输出结果
- 分析分布和趋势

### 1.2 为什么用蒙特卡洛
- 游戏系统太复杂，无法用数学公式精确计算
- 很多因素互相影响，难以单独分析
- 需要知道整体的胜率分布，而不只是单点数值

## 二、平衡性测试的核心指标

### 2.1 胜率分布
**核心指标**：各方胜率是否接近。

**判定标准**：
- 理想：各方胜率相等（1/N）
- 可接受：25%-40%（三方对战）
- 不合格：某方胜率 > 50% 或 < 15%

### 2.2 游戏时长
**指标**：平均回合数、最短/最长回合数。

**意义**：
- 太短：游戏还没展开就结束了
- 太长：玩家疲劳，体验差
- 波动太大：体验不稳定

### 2.3 资源利用率
**指标**：资源产出 vs 消耗的比例。

**意义**：
- 资源太多：花不完，经济系统没意义
- 资源太少：总是缺钱，游戏节奏太慢
- 合理：资源总是不够用，需要做取舍

### 2.4 战斗胜率
**指标**：进攻方胜率 vs 防守方胜率。

**意义**：
- 防守太强：大家都龟缩，游戏无聊
- 进攻太强：大家都速攻，策略单一
- 平衡：进攻有风险，但收益也大

## 三、蒙特卡洛测试怎么跑

### 3.1 测试步骤

```
1. 确定测试参数
   ├── 测试哪些参数
   ├── 参数范围
   └── 每次调整多少

2. 批量运行模拟
   ├── 每个参数组合跑N局
   ├── 每局用不同的随机种子
   └── 记录每局的结果

3. 收集数据
   ├── 每方胜率
   ├── 平均回合数
   ├── 资源产出/消耗
   └── 战斗结果统计

4. 分析结果
   ├── 胜率分布是否合理
   ├── 哪些参数影响最大
   └── 参数调整方向

5. 调整参数，重复测试
```

### 3.2 需要跑多少局
**经验值**：
- 快速验证：100局（看大致趋势）
- 正式测试：1000局（比较准确）
- 最终验证：10000局（非常准确）

**为什么需要这么多**：
- 随机因素多，样本少了波动大
- 胜率差5%可能只是随机波动
- 样本越大，结果越可信

### 3.3 参数扫描
系统地调整关键参数，观察胜率变化。

**例子**：
```
测试城墙强度对胜率的影响：

城墙倍率 | 防守方胜率
0.5x    | 35%
0.8x    | 42%
1.0x    | 48%
1.2x    | 55%
1.5x    | 65%
```

**结论**：城墙倍率1.0x时，防守方胜率48%，比较平衡。

## 四、极端策略测试

### 4.1 为什么要测极端策略
- 正常AI可能不会用极端策略
- 但玩家会用
- 如果某个极端策略无敌，游戏就毁了

### 4.2 常见极端策略

| 策略 | 描述 | 测试目的 |
|------|------|---------|
| **全经济流** | 只发展，不打仗 | 看经济优势能不能转化为胜势 |
| **速攻流** | 开局就爆兵进攻 | 看防守方能不能守住 |
| **龟缩流** | 只守不攻，等别人打 | 看会不会平局，或者被慢慢耗死 |
| **集中兵力** | 所有兵力打一个方向 | 看能不能快速滚雪球 |
| **流言流** | 只放流言，不打仗 | 看流言是不是太强了 |

### 4.3 怎么测
- 写一个简单的AI，只执行这个策略
- 和正常AI对战
- 看胜率是不是太高

## 五、平衡性调优流程

### 5.1 第一步：确定目标
- 三方胜率目标是多少？
- 平均游戏时长是多少？
- 进攻/防守胜率比是多少？

### 5.2 第二步：跑基准测试
- 用当前参数跑1000局
- 记录各项指标
- 作为基准线

### 5.3 第三步：参数扫描
- 找出影响最大的几个参数
- 每个参数跑一组测试
- 画出参数 vs 胜率的曲线

### 5.4 第四步：调整参数
- 根据测试结果调整参数
- 每次只调1-2个参数
- 调完再跑测试验证

### 5.5 第五步：回归测试
- 参数调好后，跑完整测试
- 确认所有指标都在可接受范围内
- 确认没有引入新的问题

## 六、常见误区

### 误区1：只看平均胜率
不对。还要看分布：
- 胜率波动大不大？
- 有没有极端情况？
- 百分位数是多少？

### 误区2：测一次就够了
不对。参数改了就要重测：
- 改一个参数可能影响很多东西
- 要回归测试
- 确保没有副作用

### 误区3：追求绝对平衡
不对。绝对平衡既不可能也没必要：
- 有一点差异是正常的
- 玩家可以通过策略弥补
- 只要在可接受范围内就行

### 误区4：只测正常情况
不对。还要测极端情况：
- 极端策略
- 边界条件
- 运气特别好/特别差的情况
