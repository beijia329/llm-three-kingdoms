## 2. 🔴 残留项：`crown.svg` 在 mask 下渲染为「实心圆盘」
`web/src/assets/icons/crown.svg` 含**不透明背景圆**：
```svg
<circle cx="128" cy="128" r="128"/>            <!-- 无 fill → 不透明 → mask 整盘遮住 -->
<circle stroke="#fff" stroke-width="18" cx="128" cy="128" r="101"/>
<path fill="currentColor" d="M64 96l18 86h92l18-86-42 32-22-56-22 56z"/>   <!-- 真正想显示的皇冠 -->
```
mask 用 **alpha**：第一个 `r=128` 圆不透明 → 整个 256×256 被遮住 → 显示为**圆盘**；皇冠路径在其内部，被吞掉。
（对照：siege-tower/scales/shaking-hands 只有 `<path>`，无背景圆 → 剪影正常。）

**影响面**：仅 **真·统一（unification）** 结算图标；timeout/stalemate/平局图标均正常。
**修复（资产侧，1 处）**：删除 `crown.svg` 里两个 `<circle>`（保留皇冠 `<path>`），或令背景圆 `fill="none"`；`npm run build` 后我复验该图标即可。
