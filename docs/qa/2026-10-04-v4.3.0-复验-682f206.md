### 🔴 残留 FAIL：unification 图标（crown）仍是**实心圆盘**
- 现象：`end_icon=crown`（= 真·统一结算）渲染为**红色实心圆**，看不出是王冠。
- 根因（asset 级，与本次 CSS 修复无关）：`web/src/assets/icons/crown.svg` 内含**不透明的背景圆** + 一圈描边圆：
  ```svg
  <svg viewBox="0 0 256 256"><circle cx="128" cy="128" r="128"/>
    <circle stroke="#fff" stroke-width="18" cx="128" cy="128" r="101"/>
    <path fill="currentColor" d="M64 96l18 86h92l18-86-42 32-22-56-22 56z"/></svg>
  ```
  该 `<circle r=128>` 铺满整个 viewBox 且**不透明** → 用于 CSS mask（按 alpha 取形）时**整块被保留** → 渲染成实心圆盘；王冠路径被圆盘吞没。
- 影响面：**真·统一结算图标**（本作最罕见的胜局）；另 `CityMarker` 的**都城加冕**也用同一 `crown.svg` → 都城徽记同样是圆盘。
- 修复（asset，1 个文件）：把 `crown.svg` 改为**纯路径（去掉两个 `<circle>`）**，或换一个 paths-only 的王冠素材。改后请在生产构建复看 `end-icon-crown`。
- 备注：`siege-tower/scales/shaking-hands/crossed-swords/castle` 等**无背景元素**，均已正确成形——即**只有 crown.svg 这一个资产**有问题。
