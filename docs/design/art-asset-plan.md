# 界面与美术方案（围观台）

> 定位：这是一个 **LLM 对局的"围观台/评测台"**，不是玩家操作的游戏。
> 美术的首要目标 = **把 LLM 的"主观智能"变得可见**（决策理由、外交博弈、战术选择），而不是堆特效。
> 原则：**不重复造轮子**——一律用可商用/开源素材（见 `assets/art/ATTRIBUTION.md`）。
> 更新：2026-10-01

---

## 1. 路线：主推 Web
- Web（React + PixiJS）天然可分享、可直播——"电子斗蛐蛐"本质是**内容**。
- Pygame 渲染层逐步降级为**本地调试通道**，不再并行投入美术。

## 2. 信息架构（一屏）
```
┌───────────────────────────────────────────────┬──────────────────┐
│ TopBar：标题 · 回合 x/24 · 参战模型标签 · 连接态 │                  │
├───────────────────────────────────────────────┤  Panel（tab）     │
│                                               │  · 决策（★核心）  │
│           势力地图（PixiJS）                    │  · 城池          │
│   hex 地形 + 势力色 + 军队 + 迷雾 + 影响力       │  · 将领          │
│                                               │  · 外交          │
├───────────────────────────────────────────────┤  · 数据          │
│ EventTicker：事件流                            │  · 事件 / 日志    │
```

**最大缺口：当前 tab 里没有「决策」——而它是灵魂。** 每回合每方产出一段"策略/决策理由"，摆出来，"主观智能"才可见。

## 7. 素材评估记录：Kenney 六角地块 —— ❌ 不接入（退役）

> 评估日期：**2026-10-03** ｜ 评估人：林绘澄（美术/视觉）
> 结论：**不接入**。素材**保留**在 `assets/art/hex/` 作为素材库，但本文件与 `ATTRIBUTION.md` 均已标注「未接入」。
> 证据图：`docs/art/screenshots/kenney-eval/`（01 放大态 α 对比、02 整图态 α 对比、03 素材本体、04 现地形色板）

### 7.1 事实先摆清楚（全部为实测，非估计）
| 项 | 实测值 |
|---|---|
| 素材数量 | **31 个 PNG**（非 24），其中基础地块 7 种 ×2 变体（`_full`）+ 植被/山岩/桥/波纹 |
| 代码引用数 | **0**。全仓只有 `ATTRIBUTION.md` / 审计文档 / README 提及，**无任何代码引用**；`web/public/art/` 下无副本 |
| 素材原生尺寸 | **65×89**（RGBA，四角透明），不透明占比 **82.85%** |
| 本作 hex 尺寸 | **55.43×64**（`HEX_SIZE=32`，`axialToPixel`；pointy-top，与素材同朝向） |
| **长宽比** | 素材 **0.730** vs 本作 **0.866** → **差 18.6%**（素材偏"高"）。等比贴入必然二选一：纵向压扁 14%，或纵向溢出 14% 压到邻格 |
| 地图规模 | 网格 **200×120 = 24000 格**，其中 `deep_water` **16970 格（70.7%）**、有 `province_id` 的陆地 **7458 格（31.1%）** |
| **整图默认倍率** | 相机 `scale=0.146533` → **1 个 hex 只有 8.1×9.4 屏幕像素**（页面实测） |
| 放大上限倍率 | `scale=1.2`（滚轮上限）→ 1 格 66.5×76.8 像素 |

### 7.2 为什么不是 A（逐条，含"看不见的对比"）
1. **整图倍率下纹理根本不存在（决定性）**。默认 `scale=0.1465`，65×89 的贴图被缩到 8×9 像素——**降采样 8 倍，纹样全部糊掉**。
   看证据图 02：A@α0.15 / A@0.35 相对现状，**没有任何"纹理"增加**，只有**配色变了**（陆地由卡其转绿、海面多出一层网格线）。
   而"整图"正是围观台的主视图（默认取景 + 战斗箭头/城池/势力色都在这个倍率上读）。
   📌 本仓已经踩过同一个坑：`GameMap.tsx:210` 注释明确写着线描山脉「**在"整图缩放"下会糊成噪点，暂不绘制**」。接入地块是把这个坑再挖一次。
2. **它不是"纹理层"，是"彩色美术"，低不透明度叠加 ≠ 只加纹理**。Kenney 地块是不透明彩色方块，叠上去必然同时改色：
   | α | plain 叠加后 | ΔE | 色相 |
   |---|---|---|---|
   | 0 | `(217,201,163)` | — | 42.2°（羊皮纸） |
   | 0.15 | `(205,200,146)` | **9.3** | 54.9° |
   | 0.35 | `(189,198,122)` | **21.9** | 67.1°（黄绿） |
   即：**α 小到纹理看不见时色已经偏了（ΔE 9.3 已高于"明显不同"阈值）；α 大到纹理看得见时已不是羊皮纸**。两头都不成立。
3. **目标本身已经达成，接入不带来新的地形信息**。计划原话是想"得到草地/森林/山/沙/雪/水"——但 `TERRAIN_PARCHMENT` **已经给了 12 种同色系地形色**（证据图 04），
   且 `parchmentTint()` 按地形出色。Kenney 只提供 7 种地块 → **地形分辨率反而从 12 降到 7**。
4. **风格冲突（证据图 01/03）**。素材是**扁平卡通体素风**：高饱和柠檬绿 `rgb(136,191,47)`、亮青 `rgb(138,222,232)`、橘棕 `rgb(198,149,102)`，
   grass 贴图还带**人字纹（herringbone）**机械重复。与本作「平涂羊皮纸 + 墨线省界 + 半透明势力色（参考三国志12）」是两个体系。网格内地形均色 ΔE：
   plain→草 **57.6**、grassland **54.6**、forest **52.7**、dense_forest **52.9**（全部是"换了个色系"级别的差距）；岩/雪/沙相对接近（25.2 / 10.9 / 16.4）。
5. **长宽比不匹配会露出接缝**。证据图 01（A@α0.15 / α0.35）可以看到六边形之间出现**细亮"勾缝"**——贴图边缘半透明 + 18.6% 长宽比差异重采样所致。
6. **性能与工程量不划算**。24000 格逐格贴图 = 24000 个带纹理的 quad，会打断现有「**单个 Graphics 一次性 `poly().fill()`**」的批处理（现为 1 个 draw）。
   且要额外做：地形→地块映射、纹理图集、LOD（远处回退纯色）、接缝处理。收益为 0（见第 1、3 条）。
7. **优先级**。本项目美术的首要目标是"把 LLM 的主观智能变得可见"（本文件开头），不是地形表现力。上述改动的成本应花在 §6 第 3/4 条（外交关系图、名场面回放）。

### 7.3 一个被证伪的假设（如实记录，不作为论据）
我原本预期"Kenney 的高频纹理 + 高饱和会**压低势力色块的可分辨度**"。实测**不成立**：
以 12 势力色 × `alpha=0.42` 半透明填充叠在 plain 上计算，势力色块 vs 底图的 CIELAB ΔE
**平均 26.4 → 28.2（+7%）**（12 方中 8 方略升，4 方下降：黄巾 −23%、刘备 −21%、刘表 −12%、袁绍 −8%）。
所以"势力色会被冲淡"**不能**作为否决理由 —— 否决理由只有 §7.2。
（另有一个次要的负面指标：陆地/海域可分度 **68.3 → 59.8（−12%）**，因 Kenney 亮青海面与陆地的明度接近。这条只是次要，不单独构成结论。）
