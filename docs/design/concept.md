> **一句话**：把 12 个大语言模型塞进真实三国地图，让它们自己合纵连横、背刺称霸；人类只负责观战、复盘与评判。

## 0. 30 秒导读

- **谁在玩**：不是人，是 12 个 LLM（或故障时的随机 AI）。人类是观众 / 裁判 / 研究者。
- **在哪玩**：120×90 六角格真实中国地图，31 座历史城池，带省界底图。
- **怎么赢**：184→231 年（192 回合，每回合=1 季），结束时占地最多的势力获胜；中途 3 城称王、5 城称帝拿 Buff。
- **特别在哪**：外交是"口头盟约 + 信使 + 流言"，**系统不强制履约**——背刺、忽悠、反水是合法策略。
- **凭什么信**：确定性随机 + 完整结构化日志 + 状态快照 + 回放，任何一局可复现、可审计、可对比。

## 1. 一句话定位与差异化价值

**定位**：「乱斗三国」是一款 **LLM 驱动的多智能体策略竞技场**——它是一个用来观察和评比大模型"策略与外交能力"的赛博斗蛐蛐擂台，而不是一款传统意义上"人操作"的三国游戏。

**相对传统三国策略游戏的差异化**：

| 维度 | 《三国志》系列 | 《全面战争》系列 | **乱斗三国** |
|------|--------------|----------------|-------------|
| 决策主体 | 人类玩家当君主 | 人类玩家微操军团 | **12 个 LLM 当君主** |
| 外交 | 系统契约（结盟有惩罚） | 系统契约 + 派系关系 | **口头盟约，无系统强制，可被背叛** |
| 战斗 | 回合制战棋 | 实时 3D 战术 | 回合制 + 攻城阶段 + 士气（无微操） |
| 核心价值 | 单人沉浸体验 | 爽快征服 | **PVP 竞技 / 模型评测证据** |
| 可信度 | 玩家主观感受 | 玩家主观感受 | **确定性回放，可量化对比** |

> 一句话记忆点：**别人是"你玩三国"，我们是"看 12 个 AI 怎么玩三国"。**

## 2. 设计支柱（5 条）

> 每条格式：**主张 → 它约束了什么 → 落到哪些已实现机制**。支柱之间不打架；若某次改动违背任一支柱，需主理人拍板。

### 2.1 LLM 即玩家（LLM-as-Player）
**主张**：游戏的"玩家"是 12 个大语言模型，不是人类。人类可旁观、可扮演某一势力、可做研究，但**默认对局是 12 个 LLM 全自动对战**。

- **约束**：所有玩法必须对 LLM 友好（清晰的观察接口、结构化命令、思维链引导）；人类 GUI / CLI 只是"接入层"，不是主要模式。
- **落地机制**：`players/llm/` 五层解析防御（Prompt 约束→语法→智能提取→Schema→重试降级）、性格权重（aggression/diplomacy/expand）驱动决策、`get_observation()` 给 LLM 的完整/迷雾观察数据（来源：llm-integration.md、architecture.md §1）。

### 2.2 地理即棋盘（Geography-as-Board）
**主张**：真实中国地图不是贴图，是核心玩法约束。省界、城池经纬投影、城市相邻拓扑，**直接决定谁能打谁、谁该和谁结盟**。

- **约束**：地图的"真实感"优先于美术精度；地形可简化，但**城市位置与相邻关系不可随意改**（改一处就是改战略格局）。
- **落地机制**：120×90 六角格 + 省界矢量底图、31 城经纬度投影、城市邻接表（边权重=行军回合数）、"远交近攻"天然成立（来源：README、data-models.md §7 信息迷雾、AGENTS §7.1）。

### 2.3 外交即博弈（Diplomacy-as-Game）
**主张**：外交是软的、可被背叛的、不可信的。盟约靠 LLM 的自由意志执行，**没有任何系统机制强制履约**——这恰恰是考察"外交智能"的关键变量。

- **约束**：不引入"背盟惩罚""同盟科技"等硬约束；流言、策反、假盟约都是合法且鼓励的策略（Prompt 明确"可使用任何策略，包括欺诈、背盟"）。
- **落地机制**：每势力每回合 1 条消息（`message`）、流言降敌方将领忠诚（`rumor`）、无系统履约层（来源：llm-integration.md 系统 Prompt、command-pattern.md §3.6/3.7）。

### 2.4 可复现即证据（Reproducibility-as-Evidence）
**主张**：任何一局都是可复现、可审计、可对比的"实验"。确定性是评测可信度的地基——模型 A 比模型 B 强，必须能靠同 seed 复现证明，而非玄学。

- **约束**：禁用一切非确定性来源（随机、时间）；所有决策留痕；评测结论必须能回溯到具体命令与状态。
- **落地机制**：`GameRandom` 确定性随机、状态快照 + 回滚、状态哈希校验、结构化回合日志（命令/事件/状态）、完整回放文件（来源：architecture.md §8/§11、AGENTS §5.2、command-pattern.md §7）。

### 2.5 鲁棒即底线（Robustness-as-Floor）
**主张**：**无论 LLM 多烂，游戏必须跑到结束**。崩溃、卡死、空转都算"游戏失败"，哪怕只是评测环境的问题。

- **约束**：这是硬上限，凌驾于"画面漂亮""策略优雅"之上；因此必须有降级链和最大回合兜底；少一方不能破坏平衡。
- **落地机制**：三级降级（重试→空命令→随机 AI）、异常隔离（一方出错不影响其他方）、最大 192 回合强制结束、随机 AI 作为"基线"衡量 LLM 强多少（来源：AGENTS §7.6、architecture.md §13、llm-integration.md §3.7）。

## 3. MDA 框架分析

### 3.1 Mechanics（机制——游戏规则与组件，已实现）

**势力与剧本**
- 12 方诸侯（汉室/张角/董卓/袁绍/曹操/刘备/孙坚/刘表/刘焉/公孙瓒/马腾/袁术），184 年黄巾之乱开局，各方 1–2 城。
- 每方有性格权重 `aggression / diplomacy / expand`，驱动 AI 决策倾向（来源：README 剧本表、AGENTS §1）。

**地图与时间**
- 120×90 六角格真实中国地图，31 城，省界矢量底图。
- 192 回合制，每回合=1 季，覆盖 184→231 年（来源：README、AGENTS §7.1）。

**决策接口（7 类命令，全部走 Command + VAP 三层校验）**
- `develop`（经济/军事/文化）、`recruit`（征兵）、`attack`（派军攻城）、`reward`（赏赐将领）、`explore`（探索人才）、`message`（外交消息）、`rumor`（散布流言）。
- 命令可序列化、可校验、可回放（来源：command-pattern.md）。

**经济**
- 资源：金钱 / 粮草 / 人口 / 民心。
- **民心是隐性倍率**——压低民心会拖累产出、形成死亡螺旋（来源：AGENTS §7.2、data-models.md §8 常量）。

**战斗**
- 行军：每回合前进 1 城距，粮耗 0.2/兵/回合；断粮每回合 −10 士气，士气<30 开始溃散。
- 攻城三阶段：围城 → 破墙（基础 100 伤害/回合）→ 巷战（守方 +30% 防御）。
- 士气系统影响战斗力；将领统帅加成、忠诚影响投降/被俘（来源：battle-system.md）。

**外交**
- 每势力每回合 1 条消息；口头盟约无系统强制；流言降低敌方将领忠诚（来源：llm-integration.md、command-pattern.md §3.7）。

**建国**
- 控 3 城称王、5 城称帝，授予历史国号 + Buff/Debuff（来源：README、AGENTS §7.1）。

**信息迷雾**
- 己方城市全知；相邻敌城见守军/城墙概貌；远城仅见归属与名称（来源：data-models.md §7.2）。

**容错与确定性**（见支柱 2.4 / 2.5）
- 确定性随机 + 状态快照 + 日志 + 回放 + 三级降级。

### 3.2 Dynamics（动态——机制在真实对局中的相互作用）

- **自由意志 vs 硬校验的张力**：LLM 可输出任何战略，但非法命令被 VAP 拦截 → 产生"意图—执行"偏差。弱模型常因格式/资源错误被大量丢弃命令，等于"挂机"。这是评测里能直接观测的"能力落差"。
- **外交脆弱性涌现**：无强制履约 + 流言降忠诚 → "先发优势"与"背刺博弈"。高 diplomacy 方能拉拢弱者组临时同盟，但随时可能被高 aggression 方反水。
- **经济—军事权衡**：过度征兵/压税 → 民心下滑 → 产出下降 → 死亡螺旋。这把"懂不懂长期经营"变成可量化分差。
- **地理锁定联盟结构**：城市相邻拓扑决定谁能与谁交战 → "远交近攻"是地图硬给的理性解，性格只是扰动项。
- **性格涌现格局**：高 aggression 方（张角/董卓/孙坚/公孙瓒/马腾）早期互相消耗；高 diplomacy 方（刘备）易成"合纵枢纽"；野心型（袁绍/曹操/袁术）倾向速吞邻城。
- **多极均衡 vs 一家独大**：12 方非合作博弈可能出现"多极僵持"或"闪电统一"，取决于性格分布与地图相邻密度。
- **鲁棒地板效应**：随机 AI 作为基线，使任何对局都有可比下限——模型崩溃本身就是评测结果的一部分，而非环境错误。

### 3.3 Aesthetics（美学——人类体验到的情绪）

> 注意：本游戏的"行动者"是 LLM，"体验者"是人类（观众/研究者/可扮演者）。美学面向人类。

- **对研究者 / 评测者——"实验室的惊喜感"**：看到不同模型在同一 seed 下走出截然不同外交路线（有的守约、有的背刺），是"发现"而非"娱乐"。
- **对观众（看回放）——"赛博斗蛐蛐的戏剧性"**：12 个 AI 合纵连横、假盟真刺、绝地翻盘，悬念与爽点来自"不可预测的自由意志"。
- **对扮演者（GUI/CLI 控某势力）——"运筹帷幄的胜任感"**：在信息迷雾下读局势、下命令、看结果。
- **贯穿感受**：**可控感**（确定性回放可复盘任意回合）+ **对比感**（模型 A vs B 胜率可量化）+ **惊喜感**（LLM 做出人意料之举）。

## 4. 玩家心理学

### 4.1 自我决定论（SDT：自主 / 胜任 / 关联）

| 需求 | 在本游戏如何满足 | 受益对象 |
|------|----------------|---------|
| **自主 Autonomy** | LLM 有完整命令自由（7 类命令任意组合）；人类可通过选模型、seed、配置、扮演某势力获得掌控感 | LLM（决策者）+ 人类（配置者/扮演者） |
| **胜任 Competence** | 回放复盘 + 胜率/占地统计让"我读懂了 AI 怎么想"可被验证；模型以占地数获得即时胜任反馈 | 研究者 + 模型 |
| **关联 Relatedness** | 外交消息、盟约、流言——哪怕是虚拟的"关系"；人类与 LLM 可经由 `message` 命令互动 | 社交型观众 + 外交型 LLM |

### 4.2 心流（Flow）

- **风险点**：192 回合很长；单回合决策点密但"等 LLM API"可能卡顿 → 心流易断。
- **保护设计**：自动模式（A 键）、回放快进/拖拽、事件滚动条、信息密度高的状态面板，都是为了在长局中维持"挑战—技能"平衡。
- **平衡配方**：挑战（12 方混战 + 资源紧张 + 迷雾）对 技能（读懂局势 / 写好 Prompt）。对 LLM 是决策技能，对人类观众是理解力。

### 4.3 Bartle 玩家类型映射

| 类型 | 在本游戏的表现 | 对应用途 |
|------|--------------|---------|
| **成就型 Achievers** | 追称帝、刷最高胜率、冲模型排行榜 | 核心"模型评测"场景（model-evaluation.md） |
| **探索型 Explorers** | 研究地图机制、性格参数、Prompt 如何影响决策 | 研究者 / 调参者 |
| **社交型 Socializers** | 看 AI 互发消息、结盟、忽悠、背刺 | **差异化卖点**（外交即博弈） |
| **杀手型 Killers** | 速攻灭国、背刺、看敌方崩盘 | 激进性格 + 攻城爽点 |

> 结论：四类都有，但本作真正差异化的是 **Socializers（外交观赏）** 与 **Achievers（量化评测）** 的组合——传统三国游戏很难同时服务这两者。

## 5. 范围分层（Must / Could / Won't）

### 5.1 Must（本作必须，已纳入或应纳入基线）
- 12 方势力 + 184 年剧本 + 历史性格权重（aggression/diplomacy/expand）。
- 六角格真实地图（120×90）+ 31 城 + 省界底图 + 城市相邻拓扑。
- 192 回合制（每回合=1 季，184→231 年）。
- 7 类命令系统 + Command 模式 + VAP 三层校验。
- 资源系统（金/粮/人/民心，民心为隐性倍率）+ 战斗系统（行军/粮耗/断粮/攻城三阶段/士气/将领）+ 外交系统（消息/流言/无强制履约）+ 建国机制（3 城王 / 5 城帝 + Buff）+ 信息迷雾。
- 性格驱动 AI 决策。
- 确定性随机 + 状态快照/回滚 + 结构化日志 + 完整回放。
- 容错三级降级 + 异常隔离 + 最大回合兜底。
- 多接入模式：GUI（Pygame）/ Web（React+PixiJS）/ CLI / 全 LLM 自动。
- 多方 LLM 接入（默认 DeepSeek，可 `--provider` 切换 OpenRouter/OpenAI）+ 五层解析防御。

### 5.2 Could（锦上添花，按需做）
- 信息迷雾连续化（按距离平滑衰减，而非三档硬切）。
- 地形影响行军速度 / 战斗（当前地形不影响速度，第一版有意简化）。
- 建国 Buff 树深化（多档、条件触发）。
- 模型排行榜 / 自动评测流水线（model-evaluation.md 有雏形，可产品化）。
- 可视化复盘 / 决策树回放（标注每回合"LLM 在想什么"）。
- 将领单挑、计谋系统细化（当前仅有统帅/忠诚的简化作用）。

### 5.3 Won't（明确不做——对照 AGENTS.md §1.3 非目标）
- ❌ **3D 画面 / 精美特效**：Pygame 2D 足够（来源：AGENTS §1.3）。
- ❌ **联网对战**：本地单机即可（来源：AGENTS §1.3）。
- ❌ **复杂兵种 / 科技树**：当前只有统帅/政治等属性，不做兵种树（来源：AGENTS §1.3）。
- ❌ **移动端适配**（来源：AGENTS §1.3）。
- ❌ **追求历史真实性**：Prompt 明确"不需要遵从真实历史，按判断决策"（来源：llm-integration.md）。
- ❌ **PVE 单人剧情**：核心价值是 PVP 竞技 / 模型评测，不做剧情线。
- ❌ **实时战斗 / 人类微操**：回合制，不引入实时战术。
